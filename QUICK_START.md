## FAQ

**Q: Can the site be hacked?**
A: No. Static site = no backend to hack. GitHub/Cloudflare provide security.

**Q: What if a dependency gets compromised?**
A: Run `npm audit`, update, redeploy. All free, takes 5 minutes.

**Q: Can I add a backend later?**
A: Yes. Could add Cloudflare Workers (free tier) if needed.

**Q: What if traffic spikes?**
A: No problem. Free hosts can handle massive traffic. No scaling costs.

**Q: Do I need to pay for a domain?**
A: No. Use free subdomain (username.github.io). Custom domain is optional.

**Q: Can I add analytics?**
